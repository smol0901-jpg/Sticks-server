# 🏷️ Sticker Printer Pro - Professional Label Printing System

## Полнофункциональная система печати этикеток и стикеров

### Особенности:
- **PWA (Progressive Web App)** - работает на ПК, планшетах и телефонах
- **Адаптивный дизайн** - автоопределение размеров экрана
- **Real-time SQLite БД** - работа в реальном времени
- **Мультиарендная архитектура** - общая база для всех пользователей
- **Ролевая система** - SuperAdmin, Admin, Manager, Employee (60+ функций)
- **Стена как в ВК** - общение, фото, видео, файлы до 100 шт
- **Конструктор этикеток** - 500+ функций для создания шаблонов
- **Поддержка принтеров** - Datamax, автоопределение, настройка бумаги
- **HACCP интеграция** - сроки годности, партии, сырьё
- **Экспорт/Импорт JSON** - сжатие GZIP, автосохранение каждые 24 часа
- **QR вход** - быстрая авторизация с телефона

### Установка:
```bash
pip install -r requirements.txt
python server.py
```

### Вход по умолчанию:
- Логин: `admin`
- Пароль: отключен (можно включить в профиле)

### API Endpoints:
- `/api/users` - управление пользователями
- `/api/templates` - шаблоны этикеток
- `/api/products` - продукты со сроками годности
- `/api/raw-materials` - сырьё и остатки
- `/api/print` - печать
- `/api/wall/posts` - стена
- `/api/messages` - личные сообщения
- `/api/upload` - загрузка файлов
- `/api/export` - экспорт БД
- `/api/import` - импорт БД

### Функции:
#### Печать (100-200):
Автоопределение принтера, поддержка Datamax, настройка размера бумаги, автоподгон по краям, QR/баркоды, даты, серийные номера, HACCP, логотипы, изображения, шрифты, цвета, слои, сетка, направляющие и многое другое.

#### Управление (50-150):
Пользователи, роли, права, дашборд, аналитика, отчёты, экспорт/импорт, бэкапы, организация, мультиарендность, аудит, уведомления, инвентарь, сырьё, отслеживание сроков, партий, серий, качество, соответствие стандартам и др.

#### Стена (20-200):
Посты, комментарии, лайки, репосты, упоминания, хэштеги, вложения, фото, видео, аудио, файлы, ссылки, шаблоны, стикеры, эмодзи, реакции, опросы, события, закреплённые, приватные, группы, каналы, ЛС, голосовые, камера, запись видео и др.

#### Конструктор (100-500):
Холст, слои, инструменты, фигуры, текст, изображения, баркоды, QR, даты, переменные, формулы, условия, циклы, функции, скрипты, макросы, шаблоны, пресеты, шрифты, цвета, градиенты, узоры, текстуры, эффекты, фильтры, трансформации, выравнивание, сетка, измерения, экспорт/импорт, печать и многое другое.
